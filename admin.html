Unlock with your GitHub key to add and edit photos. The key stays on this device only.

How do I get my key?
  1. Open github.com → Settings → Fine-grained tokens → Generate new token.
  2. Name it e.g. “travels admin”, set an expiry (up to a year).
  3. Repository access: “Only select repositories” → .
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate, copy the key, paste it here. Do this once per device.

This happens when photos are dragged straight from the Mac Photos app into the browser: Photos hands over an empty stand-in instead of the picture. To fix it:

  1. In Photos, select the photos → File → Export → Export Unmodified Original → save them to a folder.
  2. Here, click choose files and pick them from that folder (or drag them in from Finder).

"Unmodified Original" also keeps each photo's location.
